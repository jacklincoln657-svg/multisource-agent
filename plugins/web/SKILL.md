# 网页证据插件用法

## 何时用（证据升级，不是默认路径）
- 已注册本站工具**不够**回答原问实质时再用，例如：问视频「讲了什么 / 剧情」而平台只有标题。
- 其它确需站外事实的问题。
- **本站优先**：Steam / B 站 / 飞书 / 本地工具能覆盖的，绝对不调 `web_*`。

## 工具
- `web_search`（Tavily）→ 必要时 `web_fetch`
- 证据卡字段：`title` / `url` / `snippet` / `site` / `kind`

## 止损（代码硬闸，须遵守）
- 同一问题内：`web_search` 最多 2 次；`web_fetch` 最多 2 URL。
- 超限工具返回 HARD_STOP → 必须停搜并承认不足；禁止同义反复刷搜。
- 另有全局 `run_limit`。

## 证据纪律
- 外部事实只能依据证据卡；冲突则并列并标不确定。
- 禁止用记忆编版本号/日期/对照表。
- 禁止用标题/短简介脑补剧情后结束。
